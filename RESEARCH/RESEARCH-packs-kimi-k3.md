# Папки каналов (packs) для поиска

## TL;DR

Нативные папки Telegram боту недоступны → делаем свои папки в БД. Таблицы
`channel_packs` / `pack_channels` уже существуют в схеме и миграции, но не используются.
Модель: персональные папки в боте + добавление каналов из бота.

## 1. Можно ли использовать механизм папок Telegram?

**Нет — не как основной механизм** (факты по core.telegram.org/api/folders):

- **Bot API**: метода чтения папок пользователя не существует. Бот не видит ни папки,
  ни список чатов пользователя в принципе.
- **MTProto (Telethon)**: технически да — `messages.getDialogFilters` возвращает
  `dialogFilter{id, title, include_peers, exclude_peers, flags(contacts/groups/broadcasts/…)}`.
  Но Telethon-сессия принадлежит **сервисному аккаунту индексера**, а не пользователям
  бота → доступны только глобальные «папки админа», общие для всех.
- Нюансы синхронизации: папка может задаваться флагами (`broadcasts=true`) без явных
  peers → состав пришлось бы материализовывать через `getDialogs`; лимит ~10 папок
  (non-premium).

**Вывод**: нативные папки — максимум опциональный «импорт глобальных папок из аккаунта
индексера» (фаза 3). Основной механизм — свои папки в БД.

## 2. UX

- `/folders` — inline-список папок пользователя + кнопка «➕ Новая папка».
- Карточка папки: имя, список каналов, кнопки «➕ Канал», «➖ Канал», «✏️ Переименовать»,
  «🗑 Удалить», «🔍 Поиск по папке».
- Добавление канала: прислать `@username` или переслать пост из канала → строка в
  `channels`, scheduler доиндексирует на следующем цикле (~15 мин), до этого канал
  помечен «индексируется».
- Поиск: «🔍 Поиск по папке» → FSM ждёт вопрос → ответ только по каналам папки.
  `/search <вопрос>` без папки — по всем каналам (текущее поведение сохраняется).

## 3. Реализация

### Фаза 1 — MVP папок

- `src/packs/service.py` (новый): `get_or_create_user`, CRUD папок,
  `get_pack_channel_ids(pack_id)`.
- `src/bot/middlewares/auth.py`: создавать `users`-строку при первом апдейте.
- `src/bot/handlers/folders.py` (новый) + регистрация роутера в `app.py`:
  inline-клавиатуры (callback `f:<id>:<action>`), FSM (имя папки, вопрос поиска).
  `MemoryStorage` уже подключён.
- `src/bot/handlers/search.py`: пробросить `channel_ids` в `PostAnswerer.answer()` —
  параметр уже поддержан в `TitleSelector.select` / `PostAnswerer.answer`.
- Тесты: `test_packs_service.py`, `test_folders_handler.py` (паттерн FakeSession/AsyncMock).
- **Миграции БД не нужны** (таблицы уже есть).

### Фаза 2 — добавление каналов из бота

- `ensure_channel(username)` → строка в `channels` (title = @username до индексации);
  существующий `index_all_channels` подхватывает новый канал автоматически —
  межсервисных вызовов не нужно.
- Обработка пересланных постов (`message.forward_from_chat`) и `@username`.

### Фаза 3 (опционально) — импорт Telegram-папок

- `indexer/folders_sync.py`: `GetDialogFilters` сервис-аккаунта → глобальные
  read-only папки (system owner).

## 4. Открытые вопросы
