# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено

- Полное управление персональными папками и каналами через `/folders`.
- Ручная инкрементальная индексация новых постов канала.
- Ссылки на источники по ходу текста ответа: модель ставит маркеры `[N]`,
  бот превращает их в ссылки на конкретные посты.
- Инфраструктура для развёртывания на VPS: `scripts/vps_bootstrap.sh`
  (пользователь `deploy`, хардненинг SSH, `ufw`, swap, Docker),
  `scripts/deploy.sh` (проверка `.env`, сборка, миграции, контроль запуска),
  `scripts/backup_db.sh`, `scripts/watchdog.sh`, `scripts/install_cron.sh`.
- Одноразовый compose-сервис `migrate` как единственный исполнитель
  `alembic upgrade head`; bot и scheduler ждут его завершения.
- Runbook переезда с Railway на VPS: `docs/setup/vps-migration.md`.

### Изменено

- Поиск ограничен каналами из папок текущего пользователя.
- Промпт генерации ответа: прямой ответ без вступлений, короткие абзацы,
  конкретика из постов, явное указание на противоречия между источниками.
- Контекст для модели больше не содержит URL постов — ссылки подставляет бот.
- Справка бота содержит пошаговую инструкцию по работе с папками, каналами и поиском.
- Postgres в compose публикуется только на `127.0.0.1`: опубликованный порт
  обходит `ufw`, потому что Docker пишет свои правила iptables.
- У всех compose-сервисов ограничен размер логов (`json-file`, 10 МБ × 5) и
  выставлен `restart: unless-stopped`, включая `db`.
- `docker-entrypoint.sh` пропускает миграции при `RUN_MIGRATIONS=0`.
- Раздел развёртывания в README описывает VPS вместо Railway.
