# Управление каналами и папками

## Цель

Сделать `/folders` единой точкой управления персональными папками и каналами:
создание папки, переименование и удаление; добавление канала, немедленная первичная
индексация, ручное обновление новых постов и удаление связи канала с папкой.

Обычный `/search` должен искать только по каналам из папок текущего пользователя.
Отдельный интерфейс управления `/channels` не нужен.

## Не входит в задачу

- Физическое удаление общей записи канала и его постов из базы.
- Изменение схемы базы данных.
- Полная переиндексация ранее сохранённых постов через интерфейс бота.

## Границы

- `src/packs/service.py`: проверка владельца для чтения и изменения состава папки,
  выбор каналов пользователя, удаление пустой папки.
- `src/indexer/pipeline.py`: повторное использование существующей записи канала без
  дубликатов `news`/`@news`.
- `src/bot/handlers/folders.py`: карточки каналов, подтверждения удаления и запуск
  инкрементальной индексации.
- `src/bot/handlers/search.py`: ограничение поиска каналами пользователя.
- `src/bot/handlers/basic.py`: подробная инструкция без отдельного `/channels`.

## Задачи

1. **Контроль доступа и удаления, высокий риск.** Добавить owner-scoped операции
   сервиса. Удаление последнего канала удаляет папку, но не общую запись канала.
   Проверка: регрессионные тесты сервиса на чужую папку и пустую папку.
2. **Индексирование, средний риск.** Канонизировать публичный идентификатор и находить
   ранее созданный канал по username, затем использовать pipeline для немедленного
   добавления и ручного обновления. Проверка: тест pipeline на placeholder-канал.
3. **Интерфейс, средний риск.** В карточке папки оставить все действия и добавить
   карточку каждого канала с обновлением и удалением через подтверждение. Проверка:
   тесты callback и клавиатур.
4. **Персональный поиск, высокий риск.** Передавать в answerer только объединение
   каналов из папок пользователя. Проверка: тест handler на пустой набор и scope.
5. **Документация, низкий риск.** Обновить `/start`, `/help`, README, CHANGELOG и TODO.
   Проверка: self-review текста и итоговый `make check`.

## Восстановление

Изменений схемы нет. Код можно откатить одним изменением; удаление папки каскадно
удаляет только связи, общие каналы и посты сохраняются.
